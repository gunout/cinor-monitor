## 📋 Description

**Cinor Monitor** est un tableau de bord web permettant de surveiller et visualiser des données en temps réel. Le projet combine un frontend léger (HTML/JS) avec des modules d'enrichissement de données pour offrir une expérience de monitoring claire, rapide et réactive.

---

## ✨ Fonctionnalités

- 📊 **Tableau de bord interactif** — Interface web accessible directement dans le navigateur
- 🔄 **Modules d'enrichissement** — Traitement et enrichissement des données via `modules-enriched.js`
- 🎛️ **Adaptateur flexible** — Couche d'adaptation (`adapt-enriched.js`) pour intégrer différentes sources
- 📁 **Données JSON** — Stockage structuré et facilement modifiable dans `data-json/`
- ⚡ **Léger et rapide** — Aucune dépendance lourde, exécution 100% côté client

---

## 🗂️ Structure du projet

- `data-json/` → Fichiers de données JSON
- `adapt-enriched.js` → Adaptateur pour l'enrichissement des données
- `modules-enriched.js` → Modules d'enrichissement et de traitement
- `index.html` → Point d'entrée du tableau de bord

## 🚀 Démarrage

### Prérequis

Aucun prérequis particulier. Un simple navigateur moderne suffit.

### Installation

```bash
git clone https://github.com/gunout/cinor-monitor.git
cd cinor-monitor
python3 -m http.server 8000
```
Puis ouvrir : http://localhost:8000
🛠️ Technologies utilisées

    HTML5 — Structure de l'interface

    JavaScript — Logique et enrichissement des données

    JSON — Stockage des données
